Projekty

2D Jump Game

Vývoj 2D rytmické plošinové hry v jazyce Java s využitím knihoven Swing a AWT. Projekt zahrnoval implementaci vlastní fyziky, kolizního systému, dynamického načítání úrovní z JSON souborů a uživatelského rozhraní. Součástí byla také možnost přizpůsobení vzhledu hry a tvorba vizuálních efektů.

IR dekodér

Projekt zaměřený na zachytávání a dekódování infračervených signálů z dálkových ovladačů pomocí Arduina. Využívá infračervený přijímač a knihovnu IRremote pro zpracování přijatých dat.

Linuxové a serverové projekty

Praktická práce s operačním systémem Linux, konfigurace serverových služeb a správa virtuálních strojů. Zaměřuji se na práci v terminálu, síťové služby a správu serverového prostředí.
